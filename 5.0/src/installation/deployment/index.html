Deploy XMPro

XMPro 5.0 is deployed on Kubernetes. Choose the platform that best suits your environment:

Kubernetes Deployments

AWS Kubernetes (EKS) Deployment

Tip

Kubernetes on AWS: Full XMPro platform on Amazon Elastic Kubernetes Service with RDS SQL Server, optional ElastiCache Redis, IRSA, and Envoy Gateway. Three-layer Terraform (cluster + per-site infrastructure + per-site application) with Let's Encrypt TLS.

Azure Kubernetes (AKS) Deployment

Tip

Kubernetes on Azure: Full XMPro platform on Azure Kubernetes Service with Azure SQL, Key Vault, Workload Identity, and Envoy Gateway. Three-layer Terraform (infrastructure + cluster platform + per-site application) with Let's Encrypt TLS.

Note

A Windows Server 2022 deployment option is planned for a later 5.0 update. Migrating from an existing v4.x Azure App Service or legacy AWS deployment? Each Kubernetes guide includes a migration path.
